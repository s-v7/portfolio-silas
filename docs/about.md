Silas Vasconcelos Cruz authored SIGEC v2, a fiscal intelligence engine that indexed 1.1M+ ARTs on a SHA-256 blockchain and modernized it while implementing new features and integrating external APIs. SIGEC v2 includes a Sentinel-2 to PostGIS pipeline for hydrological monitoring of 20 reservoirs using NDWI and utilizes NetworkX and TSP routing across 224 municipalities in Piauí. The system runs on Flask, FastAPI, Angular 17, PostgreSQL 17, and PostGIS, deployed as 8 systemd services in production, with an orchestrator that uses the OpenAI and Claude APIs.

Silas also authored FiscalBot, an operational Telegram bot that sends automated alerts and runs a mass ART pipeline, and SistemaCrea, an ERP modernization on Jakarta EE, which includes a Maven multi-module EAR and e-MEC integration covering 4,328 IES. He developed an agent framework in Python that generates evidence-grounded README, About, and bio texts. Silas worked as Technology and Information Security Advisor at CREA-PI, with the role ending in July 2026, and is based in Teresina, Piauí, Brazil.
