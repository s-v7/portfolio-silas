# portfolio-silas

Personal portfolio of Silas Vasconcelos Cruz, and the Python agent framework behind it, **SV7 AI**, which generates the profile texts published here and checks them in code against verified evidence.

Live site: https://s-v7.github.io/portfolio-silas

## What is in this repository

| Path | What it is |
| --- | --- |
| `src/`, `public/`, `index.html` | The portfolio site: React, TypeScript and Vite, published on GitHub Pages |
| `ai/` | SV7 AI, the Python framework (see [ai/README.md](ai/README.md)) |
| `docs/` | Texts generated by SV7 AI: About, bio and profile READMEs |
| `Dockerfile`, `nginx.conf` | Container build for the site |

## Run the site

```bash
npm install
npm run dev      # Vite prints the local address; the app is served under /portfolio-silas/
npm run build    # production build in dist/
npm run deploy   # publishes dist/ to GitHub Pages
```

`npm run ai` starts the local Node server in `ai/server` (port 3333 by default).

## SV7 AI

An objective goes through a planner, a workflow builder and a parallel executor. Every generated text (profile README, About section, bio) is checked before it is accepted:

- numbers, links and e-mails must exist in the verified evidence;
- claims about roles, authorship, impact and self-assessment need the evidence to use the same word;
- a rejected text is retried with the reason, up to twice, and is never saved;
- evidence imported from READMEs, GitHub or git history stays `unverified` until it is promoted by hand.

Try it without an API key:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,anthropic]"
pytest -q                  # fake providers, no network
python -m ai.scripts.plan_workflow --objective "Write about me" --capability about
```

With a key (`OPENAI_API_KEY`):

```bash
python -m ai.scripts.plan_workflow --objective "Write about me" --capability about \
  --run --provider openai --evidence-file ai/data/profile_evidence.json
```

Automation: the `regenerate-docs` workflow runs when `ai/data/profile_evidence.json` changes and opens a pull request with the regenerated `docs/about.md` and `docs/bio.txt`. It never pushes to `main` and never merges by itself. CI runs ruff, mypy and pytest on every push.

## Limits

- The checks are rules, not understanding: the authorship check is global (it does not match a verb to a project), the word lists are English-only, and numbers written in words are not compared.
- The pass rates were measured with one model (gpt-4o-mini) on small samples.
- The classifier in `ai/scripts/train_neural_net.py` is a study: its labels come from keyword rules, and it scored 61% against a 39% baseline on 18 held-out examples (see `ECOSYSTEM_INSIGHTS.md`).
